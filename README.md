# AtlasPractice

A **Minecraft 1.8.8 Practice PvP** plugin built for competitive servers.

AtlasPractice focuses on performance, customization, and ease of use while providing a polished practice experience with modern features such as dynamic arenas, ranked queues, cosmetics, replays, parties, and much more.

> **Current Version:** 1.0.0
> **Minecraft Version:** 1.8.8 (PandaSpigot/Spigot)
> **Java:** 17

---

#  Features

##  Practice Modes

* Ranked & Unranked matchmaking
* Custom Duel system
* Party Duels
* Spectator mode
* Queue system
* Dynamic arena allocation
* Runtime arena generation

---

## 🗺️ Arena System

* One-click arena setup
* SlimeWorldManager integration
* Runtime arena cloning
* Automatic arena cleanup
* Shared arena support (configurable)
* Dynamic temporary arenas
* Arena editor & management commands

---

## 🎮 Supported Kits

AtlasPractice includes a large collection of built-in kits, including:

* NoDebuff
* Boxing
* Sumo
* Combo
* Gapple
* Archer
* Stick Fight
* Fireball Fight
* BedFight
* Bridge
* BuildUHC
* And many more...

---

## 🏆 Ranked System

* Ranked matchmaking
* Configurable ranked kit whitelist
* Elo-based progression
* Leaderboards

* Coming in next update: elo specific enemy selection.

---

## 🎨 Cosmetics

Players can unlock and use cosmetic features such as:

* Kill Effects
* Projectile Trails
* Walking Trails
* Chat Colors
* Kill Messages
* Cosmetic GUI

---

## 👥 Social Features

* Party System
* Friend System (AtlasMore Addon)
* Duel Requests
* Spectator 
* Quick Player Interaction Menus

---

## 📊 Statistics

Tracks player progression including:

* Wins
* Losses
* Winstreak
* Elo
* XP
* Coins
* Kills
* Deaths
* Match History

---

## 🎥 Replay Support

Optional integration with **AdvancedReplay** allows players to watch completed matches directly from within AtlasPractice.

---

## 🔌 Integrations

Supported integrations include:

* SlimeWorldManager (needed)
* AdvancedReplay (optional)
* PlaceholderAPI (needed)
* AtlasMore (optional)
